# Healthcare SEO & Trends Dashboard

![Dashboard Screenshot](https://via.placeholder.com/800x400.png?text=Healthcare+SEO+Dashboard+Screenshot)

A Streamlit-based dashboard for analyzing healthcare-related search trends using Google Trends data. Provides geographic insights, keyword analysis, and competitor benchmarking for healthcare providers.

## Features

- **Real-time Google Trends Integration**
- **Interactive Visualizations**
  - Time-series trends with forecasting
  - Geographic heatmaps (country/state/DMA levels)
  - Competitive analysis charts
- **Keyword Intelligence**
  - Related queries analysis
  - Trending searches tracking
- **Customizable Parameters**
  - Time range selection (7 days to 5+ years)
  - Geographic filtering (global to state-level)
  - Custom keyword inputs
- **Competitor Benchmarking**
  - Compare against major healthcare providers
  - Average interest comparison charts
